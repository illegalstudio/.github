A small, **full-remote native** software company from Italy, founded in 2019. We ship desktop apps, developer tools and hosted products, alongside custom development for clients across Europe. Everything we learn ends up in the open.

Our members' work has been used by the European Central Bank, the European Parliament, Cedefop, eu-LISA, Frontex, EFSA, EU-OSHA, DG NEAR and DG COMM.
